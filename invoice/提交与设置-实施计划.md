# 发票提交 + 设置菜单 实施计划

依据：`invoice/API文档.md` 第 4 节 `POST /api/invoices`（X-API-Token 鉴权，200=新发票，409=重复）。
网络策略：优先内网地址提交，连接失败自动回退外网地址重试（已确认）。
不引入新第三方依赖：`HttpsURLConnection`（自签名证书信任全部）+ 系统自带 `org.json`。

## 一、新增文件

### 1. `utils/AppConfig.java` — 本地配置（conf.json）
- 存储位置：`context.getFilesDir()/conf.json`，org.json 读写，损坏/缺失时回退默认值。
- 字段与默认值：
  | key | 默认值 |
  |---|---|
  | internalIp | 10.129.0.239 |
  | externalIp | 122.91.119.142 |
  | port | 12888 |
  | token | f931a466c79e818794144b2d57e153ec12dce5cfa5b26691231e75159172de1f |
  | autoSubmit | false |
- 提供 `restoreDefaults()`：仅恢复上面四项地址/端口/Token 为默认值（autoSubmit 不动）。

### 2. `utils/InvoiceApi.java` — 提交接口
- 鉴权使用 API Token 方式（已确认）：设置中的"配置Token"即 API文档.md 第 4 节外部系统调用所用的 `API_TOKEN`，请求头为 `X-API-Token: ${API_TOKEN}`，无需登录获取 JWT。
- `submit(invoiceNumber)` 同步方法（在子线程调用）：
  - URL：`https://{ip}:{port}/api/invoices`，Header：`X-API-Token: {token}`、`Content-Type: application/json`。
  - Body：`{"invoiceNumber":"..."}`；连接/读取超时 5s。
  - SSL：trust-all `SSLContext` + 放行所有主机名（对应 curl -k，自签名证书）。
  - 先试内网 IP，连接异常（不可达/超时/SSL 失败）再试外网 IP。
- 返回结果类型：
  - `SUCCESS`：HTTP 200，新发票录入成功；
  - `DUPLICATE`：HTTP 409，携带服务器 `message`（含冲突 Id 与时间）；
  - `ERROR`：内外网均失败或其他异常，携带错误信息（可重试）。
- 401 等其他状态码归入 ERROR 并带出 `detail` 内容，日志打印状态码+响应体便于排查。

### 3. `drawable/ic_submit.xml` — 提交按钮图标
- 白色上传/发送矢量图标，风格与现有 ic_gallery / ic_camera / ic_qr_code 一致。

## 二、修改文件

### 1. `AndroidManifest.xml`
- 增加 `<uses-permission android:name="android.permission.INTERNET" />`。

### 2. `activity_main.xml`
- 按钮行新增第 4 个 `ImageButton submitBtn`（图标 ic_submit，tooltipText="提交发票号码"），与现有三按钮等宽排列。

### 3. `MainActivity.java`

**提交按钮使能规则**
- 维护 `currentNumber`（当前发票号码纯文本）与 `lastSubmittedNumber`（最近一次提交成功/重复的号码）。
- 新增统一入口 `updateInvoiceNumber(String number)`，替换现有 4 处 `invoiceNumberET.setText(...)`（相册二维码、相册 OCR、摄像头/二维码扫描回填、buildReport）：
  1. 分组着色显示；
  2. `submitBtn.setEnabled(非空 && !equals(lastSubmittedNumber))`；
  3. 若 `AppConfig.autoSubmit` 开启且号码非空 → 自动调用提交。
- 修改为"别的号码"才重新启用；改回与 lastSubmittedNumber 相同的号码仍禁用。
- 识别进行中 `setButtonsEnabled` 一并临时禁用 submitBtn，结束后按上述规则恢复。

**提交流程（点击或自动）**
- 置灰按钮，日志"提交中..."，executor 子线程调用 `InvoiceApi.submit`：
  - SUCCESS（HTTP 200，后端无报错）→ Toast「发票OK」，稍后自动消失；记录 lastSubmittedNumber，按钮保持禁用；
  - 失败（409 重复、401 Token 无效、其他状态码、内外网均连接失败）→ 弹出 AlertDialog，内容为服务器返回的错误信息（409 显示 message，其他显示 detail 或异常说明），仅可点击"确定"手动关闭；按钮恢复使能可重试（409 视为已提交，记录 lastSubmittedNumber 保持禁用）。

**设置菜单（ActionBar 溢出菜单，主题已带 DarkActionBar）**
`onCreateOptionsMenu` 增加"设置"子菜单，`onOptionsItemSelected` 处理：
| 菜单项 | 行为 |
|---|---|
| 配置内网地址 | 输入对话框（预填当前值，文本），保存至 conf.json |
| 配置外网地址 | 输入对话框（预填当前值），保存 |
| 配置端口 | 数字输入对话框（预填当前值），保存 |
| 配置Token | password 输入框，不回显当前值（hint 提示已配置），保存 |
| 恢复默认值 | 确认对话框后将四项恢复默认并保存 |
| 是否自动提交 | checkable 菜单项，点击切换并持久化 autoSubmit |
| 关于 | 对话框显示「版本: V1.0」「开发者: HiSon」 |

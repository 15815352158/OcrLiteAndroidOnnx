# 数字键盘 / 手动编辑 / 设置菜单 / 圆角按钮 实施计划

## 1. 进入编辑状态默认开启数字键盘

四处编辑入口全部默认弹数字键盘：

| 位置 | 现状 | 改为 |
|---|---|---|
| 主界面发票号码输入框 `invoiceNumberET` | `inputType="none"` 不可编辑 | `inputType="number"`，点击进入编辑即弹纯数字键盘（同时开启第 2 节手动编辑能力） |
| 配置内网地址对话框 | `TYPE_CLASS_TEXT`（字母键盘） | `TYPE_CLASS_PHONE`——数字键盘且带小数点，方便输入 IP |
| 配置外网地址对话框 | `TYPE_CLASS_TEXT`（字母键盘） | `TYPE_CLASS_PHONE`（同上） |
| 配置端口对话框 | 已是 `TYPE_CLASS_NUMBER` | 保持数字键盘不变 |

## 2. 发票号码手动编辑规则

- `invoiceNumberET` 增加 `TextWatcher`：
  - 手动改动后取纯文本更新 `currentNumber`，按现有规则刷新使能：
    `非空 && 不等于 lastSubmittedNumber && 非识别中` → 启用提交按钮；改回相同号码 → 禁用；
  - **手动编辑不触发自动提交**——自动提交仍只在识别结果入口 `updateInvoiceNumber()` 里判断，
    即开启自动提交时，手动编辑后也必须由用户点提交按钮；
  - 程序回填（识别结果 setText）用 `updatingText` 标志位屏蔽 watcher，避免递归与误判；
  - 手动编辑后保持每 4 位分组着色（重新套用样式，光标置于末尾）。
- 提交成功后（成功/409）号码未改成别的仍禁用，逻辑不变。

## 3. 设置菜单扁平化 + 齿轮图标

- 去掉"设置"二级子菜单：`onCreateOptionsMenu` 直接 `menu.add(...)` 八个菜单项
  （配置内网/外网地址、端口、Token、恢复默认值、自动提交、连续扫描、关于），
  点右上角溢出按钮直接弹出这些一级菜单项；`onOptionsItemSelected` 处理逻辑不变。
- 三个点图标改通用设置齿轮：
  - 新增 `drawable/ic_settings.xml`（白色齿轮矢量图）；
  - `themes.xml` 增加
    `<item name="actionOverflowButtonStyle">@style/OverflowGear</item>`，
    `OverflowGear` 继承 `Widget.AppCompat.ActionButton.Overflow`，`srcCompat` 指向 ic_settings。

## 4. 主界面按钮圆角 + 动感效果

- 相册/摄像头/二维码三个按钮：背景由纯色 `?attr/colorPrimary` 改为新增
  `drawable/bg_btn_primary.xml`——`<ripple>`（半透明白水波纹）包裹 12dp 圆角矩形（purple_500），
  按压有水波纹扩散动效。
- 提交按钮：`bg_submit_btn.xml` 升级为 ripple 圆角版本，保留禁用灰色/使能紫色状态
  （ripple 内容用 selector），四按钮风格统一。

## 验证

- `gradlew :invoice:assembleDebug` 编译通过；
- 手测：发票号码/内网/外网/端口弹出数字键盘；手动改号码后使能正确、自动提交开启时手动编辑不自动提交；
  溢出菜单直接显示全部设置项且图标为齿轮；四按钮圆角、按压水波纹、提交禁用变灰仍正常。
